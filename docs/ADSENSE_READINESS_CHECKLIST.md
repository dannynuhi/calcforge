# AdSense Readiness Checklist

Official site URL:

https://calcforge-nine.vercel.app

Use this checklist before applying to Google AdSense. Approval is not guaranteed; the goal is to make CalcForge clear, useful, policy-safe, and easy to review.

## Content

- Original calculator pages provide a working tool, formula or method, example, limitations, and related links.
- Article pages answer a practical question in plain English and link to a relevant calculator.
- No placeholder text is visible.
- No copied or scraped content is used.
- No empty, thin, or doorway-style pages are published.
- Pages avoid fake credentials, fabricated endorsements, fabricated statistics, and unsupported trust claims.

## Trust Pages

- About page exists and explains what CalcForge does.
- Contact page exists without inventing a public email address.
- Privacy page exists and accurately describes the current static site.
- Terms/disclaimer page exists and explains that calculator results are informational estimates.
- Footer includes Privacy, Terms, About, Contact, and creator attribution.

## Ads And UX

- Ad placeholders are clearly labeled as Advertisement.
- Placeholders reserve space and do not cover calculator forms, results, navigation, or buttons.
- No page asks users to interact with ads.
- Real AdSense code is disabled until a real publisher ID is added through `NEXT_PUBLIC_ADSENSE_CLIENT`.

## Technical

- Official URL is `https://calcforge-nine.vercel.app`.
- Google Search Console verification file is available at `/google07a1f7eb87e23854.html`.
- `robots.txt` links to `sitemap.xml` and `image-sitemap.xml`.
- Internal links work.
- `npm run verify` passes.
- Search Console is verified and the sitemap has been submitted.

## Timing

Wait for some indexing and useful page impressions if possible before applying. CalcForge can be prepared for advertising, but approval, rankings, traffic, and earnings depend on Google systems and time.
